# Part 3: Simulated Incident & Investigation

## Simulated Load
Connected via RDP (or Bastion) and executed the provided PowerShell script as Administrator:

```powershell
$end = (Get-Date).AddSeconds(300)
while ((Get-Date) -lt $end) {
    1..10000 | ForEach-Object { [math]::Sqrt($_) } > $null
}
```

## Investigation Queries

**Heartbeat:**
```kusto
Heartbeat
| where TimeGenerated > ago(1h)
| summarize count() by Computer
```

**CPU utilization:**
```kusto
Perf
| where TimeGenerated > ago(24h)
| where ObjectName == "Processor"
| where CounterName == "% Processor Time"
| where InstanceName == "_Total"
| summarize AvgCPU = avg(CounterValue), MinCPU = min(CounterValue), MaxCPU = max(CounterValue) by bin(TimeGenerated, 5m), Computer
| order by TimeGenerated desc
```

## Evidence Required
- PowerShell script visible and running elevated
- Alert generated by the CPU spike
- KQL query in the editor
- Query results showing elevated CPU
- Time range visible
